# Design Guidelines

All variables are in [variables.css](../src/app/variables.css)

## General Guidelines

- Standard font size is var(--font-size)
- Standard spacing is var(--spacing-medium)
- Surfaces behind fields have var(--spacing-medium) padding and a var(--surface-border-radius) border radius
- Form widths are constrained by their parent component

## Fields (Text Fields, Pickers, Select Lists, Form Buttons)

1. Are 100% width
2. Have var(--field-size) height

## Text Fields

1. Have var(--spacing-medium) padding on the left and right
2. Have var(--white) background color
3. Have var(--border-width) width, var(--sand) colored, solid border

4. Have a var(--inner-border-radius)
   Have var(--sans-serif) font
5. Have var(--font-size) text size
6. Have var(--midnight) text color
